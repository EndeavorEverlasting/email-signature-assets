# Email Signature Assets

Public image assets for email signatures.

- `Fading_Set_Notation_Symbol.gif` — Career Presence mathematical brace animation.
- `Title_Loading_Ellipsis_Down.gif` — Work-signature sequential fading ellipsis (`.` → `..` → `...`) plus the accepted steep down-right arrow.

## Canonical Work cue contract

The Work cue is generated, not hand-edited. Its canonical owner is:

- generator: `scripts/generate_title_loading_gif.py`
- contract: `contracts/title-loading-cue.v2.json`
- pinned runtime dependency: `requirements.txt`
- generated output: `Title_Loading_Ellipsis_Down.gif`

The accepted geometry is a 128×43 canvas matching the managed Toga logo column. The ellipsis stays on the left. The arrow begins near the right edge of that column and runs down-right at about 74.249°, which the frozen combined fixture proves intersects the rendered `Field Technician` glyphs and misses `Richard Perez`.

Regenerate and verify:

```bash
python -m pip install -r requirements.txt
python scripts/generate_title_loading_gif.py
python scripts/generate_title_loading_gif.py --verify-only
```

A successful run must reproduce SHA-256 `e3c950e7d278f285ad5a7be8d9ed0bb219b0aa730ca34e80fd0d0fc371736ee5`. Any other hash is contract drift and must fail closed.

`Email-Signature` consumes the public asset URL and also carries the exact same generated bytes in `client/public/Title_Loading_Ellipsis_Down.gif` for local preview. The consumer repository validates hash, dimensions, frame count, animation timing, and Work-layout geometry.
